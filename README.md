# msupply-dashboard

Home of the msupply dashboard, an implementation of grafana with specific customisations for mSupply.

In this repository is the customised version of grafana (minor tweaks only) and an installer using Setup Factory.

## Installing or upgrading a customer server

**[installer/INSTALL-13.2.md](installer/INSTALL-13.2.md)** — the step-by-step
guide for support: which installer to use, what to back up first, and what to
check afterwards. Read it before upgrading an existing customer; version 13
needs two manual fixes that are easy to miss.
